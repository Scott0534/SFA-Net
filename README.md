# SFA-Net
The complete PyTorch code for “SFA-Net” will be uploaded after the paper is accepted.



### Data preparation:
- **BUSI dataset:**
Download the BUSI dataset from [Official Website](https://scholar.cu.edu.eg/?q=afahmy/pages/dataset). 

- **Dataset B:**
Download the Dataset B from [Official Website](https://helward.mmu.ac.uk/STAFF/M.Yap/dataset.php).

- **BUSBRA dataset:**
Download the BUSBRA dataset from [Official Website](https://github.com/wgomezf/BUS-BRA).

- **TN3K dataset:**
Download the TN3K dataset from [Official Website](https://github.com/haifangong/TRFE-Net-for-thyroid-nodule-segmentation) .

### Pretrained model:
You should download the pretrained PVT model from [Google Drive](https://drive.google.com/drive/folders/1d5F1VjEF1AtTkNO93JwVBBSivE8zImiF?usp=share) or [PVT GitHub](https://github.com/whai362/PVT/releases/tag/v2).
